# ADR-004: 모니터링 봇 전략별 독립 포지션

## 상태
결정됨 (2026-04-07)

## 맥락
기존 trade_executor는 전체 전략 통틀어 1개 포지션만 허용했다. S1이 먼저 진입하면 S2/S6 신호가 나와도 무시되어, 3개 전략을 활성화한 의미가 없었다.

## 결정
전략별로 독립 포지션을 관리한다. _open_position(단일) → _open_positions(전략명 키 딕셔너리). 같은 전략은 동시 1개, 다른 전략끼리는 동시 보유 가능.

## 이유
- 단일 포지션: 구현 단순하지만 전략 간 경쟁으로 신호 유실
- 독립 포지션: 각 전략의 실전 성과를 독립적으로 추적 가능, 페이퍼 트레이딩 목적에 부합
- 자금 분할은 size_usdt 파라미터로 이미 제어 가능

## 결과
- 최대 3개 포지션 동시 보유 가능 (활성 전략 수만큼)
- 텔레그램 메시지에 전략명과 활성 포지션 수 표시
- check_exit()이 모든 포지션을 순회하도록 변경
