# ADR-002: 캔들 내 TP/SL 판정을 시가 거리 기반으로 변경

## 상태
결정됨 (2026-04-07)

## 맥락
같은 캔들에서 고가가 TP에 닿고 저가가 SL에도 닿는 경우, 기존 코드는 무조건 TP를 먼저 체크했다. 실제로는 SL이 먼저 터졌을 수 있어 수익이 과대 추정되는 문제가 있었다.

## 결정
TP/SL 둘 다 해당 캔들에서 닿을 수 있는 경우, 시가(open)에서 더 가까운 쪽이 먼저 체결된 것으로 판정한다.

## 이유
- 보수적 접근(항상 SL 우선): 비관적 편향이 생겨 전략 평가가 왜곡됨
- 시가 거리 기반: 시가에서 가까운 타겟이 먼저 도달했을 확률이 높다는 합리적 가정
- 하위 타임프레임 참조: 정확하지만 데이터 의존성이 커지고 복잡도 과다

## 결과
- 기존 대비 수익률이 소폭 하락할 수 있음 (낙관적 편향 제거)
- Numba 캐시를 삭제해야 변경이 반영됨
- 백테스트 결과의 신뢰도가 향상됨
