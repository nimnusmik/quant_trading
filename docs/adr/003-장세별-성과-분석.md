# ADR-003: 장세별 성과 분석 (레짐 분류 → 분석)

## 상태
결정됨 (2026-04-07)

## 맥락
전략이 상승장/보합장/하락장 중 어디서 수익을 내는지 알 수 없었다. 장세에 따라 전략을 자동 전환하는 방법(A)과 성과만 분석하는 방법(B)을 검토했다.

## 결정
자동 레짐 스위칭(A)이 아닌, 장세별 성과 분석(B)을 채택한다. ADX≥25 + EMA 정배열/역배열로 상승/하락/보합을 분류하고, 각 거래의 진입 시점 장세를 기록하여 장세별 metrics를 산출한다.

## 이유
- A(레짐 스위칭): 장세 판단 기준 자체가 새로운 과적합 레이어가 되고, 실시간 장세 판단은 사후적으로만 명확함
- B(분석): 코드 변경 최소, 과적합 위험 없음, 실전에서 사람이 판단 근거로 활용 가능
- B의 결과를 보고 A 필요 여부를 판단해도 늦지 않음

## 결과
- Trade dataclass에 entry_regime 필드 추가
- 최종 요약에 장세별 성과 테이블 출력
- regime_breakdown CSV 저장
- fold_regime_analyzer.py의 compute_adx() 재사용
